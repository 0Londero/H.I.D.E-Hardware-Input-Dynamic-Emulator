# Changelog

Todas as mudanças notáveis deste projeto serão documentadas neste arquivo.

O formato segue o [Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/) e este projeto adota o [Versionamento Semântico](https://semver.org/lang/pt-BR/).

## [1.0.0] - 2026-11-04

### Adicionado
- Nova identidade do projeto: **HIDE · Hardware Input Dynamic Emulator**.
- Cabeçalho da interface web com nome do hardware (Raspberry Pi Pico RP2040), botão de especificações e versões (App e Firmware).
- Painel de especificações de hardware na interface (CPU, clock, SRAM, Flash, USB, FPU).
- Controle de versão centralizado no frontend (`APP_VERSION` e `FIRMWARE_VERSION`).
- Este arquivo (`CHANGELOG.md`).

### Alterado
- Renomeado "HID Automation Suite" para "HIDE · Hardware Input Dynamic Emulator".
- Versões do aplicativo e do firmware reiniciadas em 1.0.0 (base para publicação no GitHub).

### Observação
- Versões internas anteriores (firmware até v3.7) foram consolidadas nesta versão 1.0.0 inicial.

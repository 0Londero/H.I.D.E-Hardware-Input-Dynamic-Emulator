# Perfis

Esta pasta está **vazia de propósito**. Ela existe para organizar melhor o
projeto: guarde aqui seus perfis de configuração, separados por arma e jogo,
por exemplo `csgo-ak47.json`, `valorant-vandal.json`, etc.

O site (`html/index.html`) salva e carrega perfis em arquivos `.json` pelos
botões "Salvar" e "Carregar". Ao salvar, você pode escolher esta pasta para
manter seus presets junto do repositório e bem organizados.
